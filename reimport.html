01 — How it works

Right-click. Reimport. Keep creating.

Reimport updates instances in-place and non-destructively — only modifying the properties that actually changed in the source file. Welds, part colors, scripts, and other Studio-side edits stay intact.

File paths and settings persist across Studio sessions, so once a Model or SurfaceAppearance is linked to a source file, future updates are a single click.

02 — Get started

Two minutes to your first reimport.

  1. Open Studio and go to File > Beta Features.
  2. Enable Reimport and restart Studio.
  3. Right-click any Model or SurfaceAppearance in the Explorer.
  4. Choose Reimport — or hit Alt + Shift + R.
  5. Pick the source file on first use; settings persist after that.

Check the Configure dialog title bar to confirm your version. New fixes ship over-the-air, often within hours.
